# AnaxiGraph 0.6.1

This patch carries the concise, durable semantic mapping improvements from 0.6.0 into production
while preserving the taxonomy-size fix already running there. A repository-wide taxonomy for a
large codebase may exceed the single-file submission limit even when its module entries are short.

Taxonomy proposals and reviews now allow 1,000 bytes per module, bounded between 1 MB and 2 MB.
Single-file descriptions retain their existing 1 MB ceiling; the HTTP request-body ceiling is
unchanged. This transport allowance does not require longer model output or change the five-field
mapping format, economical background handoff, output-cutoff recovery, or shared worker limits.

The patch reuses the existing validator and adds three production lines, bringing the exact source
budget to 64,300 lines. There are no new interfaces, dependencies, or database migrations. The index
schema remains 11. Existing results and checkpointed work are retained; old mapping jobs refresh
when the new semantic contract is prepared.
