# AnaxiGraph 0.6.1

Published to PyPI and deployed to production on 11 September 2026. This patch carries the concise,
durable semantic mapping improvements from [0.6.0](0.6.0.md) into production while preserving the
taxonomy submission fix already running there.

Repository-wide taxonomy proposals and reviews allow 1,000 bytes per module, bounded between 1 MB
and 2 MB. Single-file submissions keep their 1 MB ceiling, and the HTTP body ceiling is unchanged.
This transport allowance does not require longer model output or change the five-field mapping
format, flexible writing guidance, bounded output-cutoff recovery, or economical background handoff.
Shared execution continues to support 30+ workers.

The patch reuses the existing validator and adds three production lines, bringing the exact source
budget to 64,300 lines. There are no new interfaces, dependencies, or database migrations. The index
schema remains 11. Saved results remain available; the new semantic contract refreshes affected
work when mapping is next prepared.
