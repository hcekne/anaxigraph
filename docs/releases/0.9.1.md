# AnaxiGraph 0.9.1

Published to PyPI. Production deployment is not yet recorded.

This patch includes the [0.9.0 semantic graph redesign](./0.9.0.md) and fixes an intermittent
storage-measurement failure found by release CI during history recovery.

SQLite can remove its WAL or shared-memory file during a normal checkpoint. Measuring those files
with separate existence and size checks could raise `FileNotFoundError` and fail an otherwise valid
history job. Storage accounting now treats a file that disappears during measurement as zero bytes.
Permission errors and other I/O failures still propagate, and storage limits remain unchanged.

Deterministic regressions exercise disappearing sidecars in storage accounting and history
measurement, alongside the original durable-job recovery test. The upgrade and migration guidance
in the [0.9.0 notes](./0.9.0.md#upgrade-and-validation) applies to this patch.
