# AnaxiGraph 0.7.0

Published to PyPI on 12 September 2026. Production deployment is not yet recorded.

A four-book architecture review of the repository itself produced ten work items, and this release
carries all ten. The theme is honesty about evidence: where an earlier version presented a number or
a status that sounded stronger than what it had actually checked, it now reports what it checked.

## What a reader sees differently

Reassessment advice reports the confidence a source actually recorded. It previously reported a
pattern's opportunity score under that name, which overstated every finding, and it took the
enclosing dossier's confidence for an individual unused-code candidate. A recorded zero, a recorded
number, and no recorded value are now three distinct states, and a consolidation strength score is
shown as a score rather than converted into a confidence it never was.

Fresh-eyes grounding no longer calls a recommendation confirmed because the names it cites resolve.
Resolving a name proves the name exists. The report now answers three separate questions: whether
the references resolve, whether the claim about the code is supported, and whether the behavior was
verified, and it says unchecked for the two it did not answer. Grounding reports saved by the
previous contract are projected forward, so no stored review is lost.

A recommendation may carry a bounded transformation: the exact target, preconditions, a short
ordered sequence, the behavior that must survive, a verification command, and a rollback. It may
also carry a result, but a result counts as a behavior check only when a tool that actually ran it
supplied the outcome and named the revision it ran on. AnaxiGraph never runs the change, so anything
else reports as unchecked on the grounded item and in the dashboard, where a failed check is shown
rather than hidden.

An understandability assessment may record what an interface makes its callers carry, and the
Architecture Charter may scope a term's meaning and name the area that owns a rule. The bundled
pattern catalogue gained the five Gang of Four object and interface patterns it could not previously
name, including Singleton as a failure mode. Every one of these fields is optional, so assessments,
charters, and reviews saved before this release stay valid and no repository re-map is forced.

## What a maintainer sees differently

The size ceiling is now a prompt to look rather than a verdict. When a module is over or near the
ceiling, the checker reports whether any part of it is reached from nothing else in it and names
that part, instead of naming the longest definition, which is a size argument that can leave two
modules that must be edited together. When no such part exists it says so, and the route is a
reviewable `cohesive_exceptions` entry naming the decision the module hides and at least two change
tasks a split would spread across two modules. The quality checker asks the opposite question too,
naming a module whose public functions all forward to one neighbour and that serves at most one
caller, so inlining is weighed alongside splitting.

A new opt-in benchmark asks real questions this repository faced, at the revision it faced them,
under the budget the recorded answer was written to, and grades the model answer and the recorded
one under opaque labels. Its report leads with coverage and misses rather than a score and withholds
any headline rate while a task was already acted on, while a reference answer was not written by a
human, or while the grader was unsure. The committed fixture is in exactly that state, so it
rehearses the protocol and does not measure anything yet.

## Cost and compatibility

Thirteen commits, 76 files, one new module. The exact production source budget moves from 64,345 to
64,570 lines, a net 225, after removing 45 lines of duplication: one AST naming helper for the
analyzers instead of two, one snapshot-replay algorithm instead of two, the priority and
rule-attention wording defined once in the foundation layer, one snapshot metadata reader, one CLI
database default, and an unused instruction helper deleted. The quality-policy and benchmark work
adds no production lines.

No new dependencies, no new endpoints, and no database migration. The index schema remains 11. The
grounding contract moves to `fresh-eyes-grounding-v2` and reads `v1` reports without re-running
them; every other semantic input hash is byte-identical, so saved semantic work is untouched.
