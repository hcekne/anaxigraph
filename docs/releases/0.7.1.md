# AnaxiGraph 0.7.1

This is a release candidate. Publication is pending, and nothing below should be read as evidence
that the version is available or deployed.

A corrective release. 0.7.0 extended several stored contracts with optional fields and kept them
out of each object's `required` list so that documents saved earlier stayed valid. That is correct
for validating storage and wrong on the wire: the strict structured output used by the Codex
executor requires every property of an object to be required. The repository architecture
synthesis, detailed file reviews and fresh-eyes reviews were rejected with HTTP 400
`invalid_json_schema` before any analysis began.

## Changes

- The Codex adapter builds its own wire schema in which an optional field becomes required with a
  nullable alternative, and turns those nulls back into absence before canonical validation. The
  stored contracts, saved documents, input fingerprints, other providers and the public schemas are
  unchanged. A null in a genuinely required field, and any unknown field, still reaches validation.
- A provider failure keeps the terminal error the provider reported. Previously only the first
  thousand characters of standard error survived, so an unrelated permission warning masked the
  schema rejection and the first diagnosis went the wrong way.
- `compact_architecture_charter` derives its sections from the Charter schema instead of a list
  maintained separately, which is what dropped scoped definitions from every partial reduction
  after 0.7.0 introduced them.
- Authorising a failed job for retry moves its attempt ceiling by one rather than resetting the
  count to zero. A job that keeps failing no longer looks untried after each authorisation.
- Semantic maps produced by 0.5.x are recognised through their released three-field fingerprint
  where the original evidence and prompt match, so upgrading does not queue a redundant re-map.

## Compatibility

The AnaxiIndex schema remains 11. No new dependency, endpoint, service or migration. Saved
semantic work is retained; a rehearsal against a completed 2,018-file map re-linked 4,036 file
descriptions and 33 architecture summaries with zero model calls and unchanged document JSON.

## Known and not fixed here

- Chunked and reduced analyses construct a result without carrying cache counters or the
  usage-reported flag forward, so their totals record as unknown usage. Do not read those zeros as
  free execution.
- The worker executes in batches, so a slow member can delay the next batch rather than each free
  slot refilling continuously.
