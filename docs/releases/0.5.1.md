installation reports 0.5.1. Production acceptance is tracked separately below;
publication does not claim that the deployment or AI workflows have completed.

  semantic tables before compatibility compaction. Preserve canonical file facts,

## Compatibility and evidence

This patch keeps schema version 11. Upgrades from the supported released schemas
still use a validated automatic backup and atomic migration. An index already
affected by 0.5.0 receives a targeted transactional constraint repair; it does not
need its immutable facts or AI descriptions regenerated. Back up before cutover,
and retain the matching old image and index for rollback.

The regression fixture reproduces the released inline foreign-key declarations,
not merely a fresh schema with its version number changed. Both schema-10 upgrade
and schema-11 repair now exercise saved-document reuse, scope upserts, job claiming,
submission, and document insertion after initialization. Dedicated recovery tests
retain connection references to prevent garbage collection from hiding leaks and
exercise read-only legacy backups and nonempty-journal refusal.

On 8 September, **36 focused migration/recovery/checkpoint tests** passed, as did
**42 combined hook, legacy-schema, and recovery regressions**. Whole-repository
lint, format, size, and architecture checks passed. All seven required
[PR CI checks](https://github.com/hcekne/anaxigraph/actions/runs/34244154399) passed.

The first real pre-push run completed **990 of 991 tests**, with **93.43% total
coverage** and **100% changed-line coverage (47/47)**. It correctly blocked the push:
one hook test inherited the outer push's branch variables instead of isolating its
temporary repository. After isolating those variables, the complete real push gate
passed **all 991 tests**, with the same coverage totals, on commit
`4731c81f56804bec5bf7edd74f84f20419878887`. No hook or runtime check was skipped.

The clean candidate also passed **all 40 dashboard browser contracts**, both
