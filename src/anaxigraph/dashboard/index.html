Initialize it beside the code

Run one non-destructive command from the repository you want to understand. Use uv for a local runtime or the Docker option for a container. Existing source is preserved; the tracked anaxigraph/ record carries reusable knowledge between clones.

  1. Start a local runtime from the target repository
    uvx --from anaxigraph anaxigraph serve --repository . --scan-on-start
  2. Open its dashboard
    http://127.0.0.1:8765
Docker guide →
Run in Docker instead
uvx --from anaxigraph anaxigraph init . --start

The Docker guide also covers an experimental multi-repository registry for one trusted operator. Keep it on loopback or behind SSH, never on an untrusted or shared network.
