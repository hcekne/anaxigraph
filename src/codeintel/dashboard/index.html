Mount once, then allowlist

A running browser cannot create a Docker host mount. Add the parent folder to .env, register its container path, then recreate the service.

  1. Mount your repository collection
    ANAXIGRAPH_REPOSITORIES_ROOT=/absolute/path/to/repos
  2. Add its container path to repositories.yml
    repositories:
  my-project:
    path: /repositories/my-project
    config: /repositories/my-project/.anaxigraph.yml
    history_snapshots: 64
  3. Apply the operator configuration
    docker compose up --build -d
